# Food App
Food App on ruokahävikin vähentämiseen tähtäävä sovellus, jonka avulla käyttäjä voi tallentaa elintarvikkeita ja niiden päiväyksiä sekä saada muistutuksia tuotteiden lähestyvistä päiväyksistä.

Tavoite
Projektin tavoitteena oli yhdistää käyttäjälähtöinen suunnittelu, digitaalinen innovaatio ja kestävä kehitys. Sovellus pyrkii helpottamaan arkea, tehostamaan ruoan käyttöä ja edistämään vastuullisempia kulutustottumuksia.

Jatkokehitys
Sovellusta voidaan tulevaisuudessa laajentaa esimerkiksi ostoslistoilla, reseptiehdotuksilla ja älykkäillä muistutuksilla.
